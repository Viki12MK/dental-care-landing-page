# 🦷 Lumora Dental Landing Page

A modern, fully responsive landing page for a fictional dental clinic built with **HTML5, CSS3, and Vanilla JavaScript**. The project focuses on clean UI, accessibility, smooth animations, and an excellent user experience across desktop, tablet, and mobile devices.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/lumora-dental.git
```

Open the project folder:

```bash
cd lumora-dental
```

Run the project by opening:

```
index.html
```

No build tools or dependencies are required.
